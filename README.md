# SulitGas Watch

A real-time fuel price tracker for Cebu drivers — jeepney, tricycle, and delivery riders checking and reporting pump prices as they happen.

## What it does

- **Live station map** — real gas stations across Cebu City, Mandaue, Lapu-Lapu, and Cordova, sourced from OpenStreetMap
- **Crowdsourced price reports** — drivers report what they see at the pump, prices update for everyone in real time
- **Price comparison** — see the cheapest nearby station at a glance, sorted and filterable by fuel type
- **Near Me** — real GPS-based distance to every station
- **Trends dashboard** — price gauges and news for diesel, gasoline, premium, and kerosene

## Planned features

- **AI photo verification** — snap a photo of the price board, AI reads and confirms the price automatically
- **AI price forecasting** — weekly analysis of fuel news to predict upcoming price hikes or rollbacks
- **SMS reporting** — report prices via text message for drivers with limited data access

## Tech stack

- React + Vite
- Supabase (database + backend)
- React Router
- Leaflet + OpenStreetMap (maps and station data)
- Google Gemini API (planned — AI photo reading)

## Status

Actively in development — built as a learning project, step by step, from the ground up.
